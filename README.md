# SignGuard AI — AI-Powered Signature Forgery Detection

**Project Duration:** October 1, 2026 – October 31, 2026  
**Development Period:** 1 Month  
**Technology Stack:** Python, PyTorch, Siamese CNN, FastAPI, React, Vite, JWT Authentication

## Project Overview

SignGuard AI is a full-stack AI-powered signature verification system designed to identify potential signature forgeries using deep learning.
